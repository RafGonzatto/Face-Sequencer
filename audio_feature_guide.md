# Audio Feature Usage Guide

## Overview

The Face Sequencer Pro now includes audio-driven animation timing to create more accurate lip-sync animations. This guide explains how to use these new features effectively.

## Audio Upload and Processing

### Uploading Audio Files

1. In the Audio Input section, click the "Choose Audio File" button.
2. Select a supported audio file format (.mp3, .wav, .ogg, .flac, or .m4a).
3. After selecting a file, click the "Upload Audio" button to upload and process the file.
4. The system will automatically analyze the audio and extract timing information.

### Switching Between Manual and Audio-Driven Timing

1. Use the "Timing Mode" toggle switch to change between manual and audio-driven timing.
2. When set to "Audio-driven", the system will use the timing extracted from your audio file.
3. When set to "Manual", it will use the traditional frame duration settings.

## Audio Visualization and Controls

### Audio Waveform

- The waveform visualization shows the amplitude of your audio over time.
- Red markers on the waveform represent detected words or phonemes in the audio.

### Playback Controls

- Play/Pause button: Control audio playback
- Progress bar: Click anywhere to jump to a specific point in the audio
- Time displays: Show current playback position and total duration

## Real-Time Sync Preview

### Word Highlighting

- During playback, the current word being spoken is highlighted on the waveform.
- The "Current Word" display shows the word being spoken at the current time.

### Animation Synchronization

- When in audio-driven mode, the face animation will automatically sync with the audio.
- Each detected word/phoneme in the audio will trigger the appropriate mouth shape.

## Building Sequences with Audio

1. Upload and process your audio file.
2. Toggle to "Audio-driven" timing mode.
3. Enter your text in the Text Input section.
4. Click "Build Sequence" to create a sequence using audio-based timing.
5. The preview will show how the animation syncs with the audio.

## Tips for Best Results

- Use clear, high-quality audio recordings for the best alignment results.
- Make sure the text input exactly matches what is said in the audio.
- For Portuguese audio, the system is specially optimized for accurate lip-sync.
- Check the Preview to ensure the sync looks natural before exporting.

## Troubleshooting

- If the audio and animation appear out of sync, try re-uploading the audio file.
- Make sure your text input matches the audio content.
- If certain words aren't being detected, try adjusting the text to match exactly what is spoken.
